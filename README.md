# ことばモンスター(フランス語学習育成ゲーム)

フランス語の単語と構文を学びながら、モンスターを育てるブラウザゲームです。
ブラウザで `index.html` を開くだけで遊べます(ビルド不要・依存ライブラリなし)。

## 主な機能

- **単語の学習・バトル・復習**: 4択問題などで単語を覚え、習得した語数でモンスターが進化し、称号が増えます。
- **単語図鑑**: カテゴリ・品詞で絞り込み、検索ができます。冠詞・性・変化形・例文を確認できます。
- **構文トレーニング**: 選択・語順整序・空欄補充で、あいさつや買い物などの場面別の構文を学びます。
- **BOTおまかせ復習**: 復習を自動で進める観戦・高速復習モードがあります。
- **フランス語の読み上げ**(ブラウザの音声が使える場合)。
- **表示テーマ**(ライト / ダーク)と、**キーボードショートカット**(割り当ての変更が可能)。
- **学習記録の書き出し・読み込み**(ブラウザの `localStorage` に自動保存)。

各機能の挙動は [docs/SPECS.md](docs/SPECS.md) にあります。

## 技術構成

- HTML・CSS・素の JavaScript(フレームワーク・ビルド環境なし)。
- 教材は `data/` のデータファイルで管理するデータ駆動型です。教材を足しても、ゲームのコードは修正しません。
- 学習記録は `localStorage` に保存します(サーバーなし)。
- 検証・テストの実行には Node 18 以上が必要です(外部パッケージは不要)。

## 起動方法

`index.html` をブラウザで開きます。

## 主要なコマンド

```
npm test                  # 構文チェック + 教材の検証 + すべての自動テスト
npm run validate          # 単語・構文データの検証(スキーマと編集ルール)
npm run content:status    # 教材の件数・次に使うID・偏りの確認(読むだけ)
npm run check             # 全 .js の構文チェック
```

そのほかのコマンド(整形など)は [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) にあります。

## ディレクトリ構成

```
index.html     画面の土台(スクリプトの読み込み順もここ)
css/           見た目(style.css)
data/          教材データ(words.js 単語 / phrases.js 構文)
src/app.js     ゲーム本体(画面・操作・学習記録)
src/lib/       画面から独立したロジック(単語・構文・キー割り当て・育成・読み上げ)
scripts/       教材の検証と確認(ゲームを起動せずに実行)
tests/         自動テスト(fixtures/ は出荷済み教材の基準データ)
docs/          ドキュメント
```

## 教材を追加するときの要点

単語・構文は、**データファイルの末尾に足すだけ**で増やせます(件数の上限なし)。

1. `npm run content:status` で次のIDを確認し、`data/words.js` / `data/phrases.js` の末尾に追加する(単語を先に、構文は後に)。
2. `npm run validate` を**エラー 0・警告 0**にし、`npm test` を通す。
3. フランス語の内容(性・活用・自然さ・空欄の正解が一意か)は人が確認する。検証に通っても、言語的な正しさは保証されません。

**既存のIDは変更・削除・再利用しない**でください(学習記録がIDで紐づいています)。詳しい手順と決まりは [docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md) を参照してください。
