# 教材追加ガイド(単語・構文)

教材(単語・構文)を追加する人のための手順と決まりです。教材は**データファイルの末尾に足すだけ**で、
ゲームのロジックや既存のテストを修正せずに増やせます(件数の上限はありません)。

- 開発環境・コマンド・コードの構成は [DEVELOPMENT.md](DEVELOPMENT.md)
- 学習記録の保存形式・各機能の挙動は [SPECS.md](SPECS.md)

## 1. 追加の流れ

1. `npm run content:status` で、現在の件数・**次に使うID**・カテゴリ/レベル/場面の偏りを確認する(読むだけ)。
2. **単語**: `data/words.js` の `WORDS` の末尾に `W('w…', ...)` を足す(§3)。新しいカテゴリを使うときだけ、同じファイルの `CATEGORIES` の**末尾**に追加する。
3. **構文**: `data/phrases.js` の `PHRASES` の末尾に追加する(§4)。新しい場面は `PHRASE_SCENES` に追加する。構文で使う単語が `data/words.js` に無いときは、**先に単語を追加**してから参照する(§5)。
4. `npm run validate` を実行し、**エラー 0・警告 0** にする。
5. `npm test` を実行する。教材を足しただけでテストが失敗するときは、テストではなく**教材(またはこのガイドの決まり)を見直す**。
6. フランス語の内容を人が確認する(§6)。**検証に通ることは、フランス語が正しいことの保証ではありません。**
7. **出荷するとき**(その時点の教材を確定するとき)だけ、§8 の手順で基準ファイルを追加する。

## 2. ID の付け方と守ること

| 種類 | 形式 | 次の番号 |
|---|---|---|
| 単語 | `w` + 数字(`w01`〜`w09` は2桁、`w10` 以降はそのまま。`w100` のあとは `w101`) | **現在の最大番号 + 1**(欠番を作らない) |
| 構文 | `p` + 数字(`p99` までは2桁ゼロ埋め、`p100` 以降はそのまま) | **現在の最大番号 + 1**(欠番を作らない) |

- 現在の最大番号・次のIDは `npm run content:status` で確認します(件数やIDは古くなるので、ドキュメントには書きません)。
- **ID は一度決めたら変更・削除・再利用しません。** 学習記録が ID で紐づいているためです(§7)。
- 欠番・重複・形式違いのIDは `npm run validate`(`scripts/validate_policy.js`)がエラーにします。
- 教材は新しい ID で**末尾に**足します。既存の語・構文の並び順も変えません(並び順がそのまま学習順です)。

## 3. 単語(`data/words.js`)

### 記述例

> ⚠️ **下の `w9001`〜`w9004` は説明用のサンプルのIDです。そのままコピーして使わないでください。**
> 実際に追加するときは、`npm run content:status` が示す「次のID」から始まる連番に置き換えます。
> 連番から外れたID(`w9001` など)や重複したIDは、`npm run validate` がエラーにします。
> また、末尾の行の直後に足すときは、それまで最後だった行の末尾に `,`(カンマ)が必要です。

```js
// W(id, カテゴリ, 冠詞, 性, フランス語, 日本語訳, 絵文字, 発音(カタカナ・目安), 例文, 例文訳, { 追加情報 })
// 名詞(冠詞と性が必須。品詞は自動で名詞)
W('w9001', '自然', 'la', 'f', 'lune', '月', '🌙', 'リュヌ', 'La lune est belle.', '月は美しい。',
  { level: 'A1', forms: { plural: 'lunes' } }),
// 動詞(冠詞・性は ''。pos を指定。不定詞で登録。present に6人称を je, tu, il, nous, vous, ils の順で)
W('w9002', '基本の動詞', '', '', 'courir', '走る', '', 'クリール', 'Je cours dans le parc.', '私は公園で走ります。',
  { pos: 'verb', level: 'A2', forms: { present: 'je cours, tu cours, il court, nous courons, vous courez, ils courent' } }),
// 形容詞(fem=女性形は必須。mp・fp も入れる)
W('w9003', '形容詞・副詞', '', '', 'lent', '遅い', '', 'ラン', 'Le train est lent.', '電車は遅い。',
  { pos: 'adjective', level: 'A2', forms: { fem: 'lente', mp: 'lents', fp: 'lentes' }, alt: ['ゆっくりした'] }),
// 前置詞・代名詞・接続詞・副詞・数詞など(冠詞・性は ''。pos を指定)
W('w9004', '疑問詞・前置詞・接続詞', '', '', 'derrière', '〜の後ろに', '', 'デリエール', 'Le chat est derrière la porte.', '猫はドアの後ろにいます。',
  { pos: 'preposition', level: 'A2' }),
```

サンプルは実際のスキーマ(`W(...)` の引数の順・`pos` / `forms` の書式・登録済みのカテゴリ)で書いてあり、既存の教材と重複しない語(`lune` `courir` `lent` `derrière`)です。`data/words.js` には登録していません。

### フィールド一覧

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | ○ | 一意の文字列(英字で始まり英数字/_/-、32文字以内)。付け方は §2 |
| `cat` | ○ | カテゴリ。`CATEGORIES` に登録したもの(綴りミスはエラー) |
| `art` / `g` | 名詞のみ ○ | 冠詞(`le la l' un une les des`)/ 性(`m` `f`)。冠詞と性の矛盾はエラー。名詞以外は `''` |
| `fr` / `ja` | ○ | フランス語(名詞は冠詞を除く)/ 日本語訳 |
| `emoji` | | 絵文字(省略可)。「絵→仏」問題は絵文字のある名詞だけ。名詞以外で使うなら `img: true`、名詞でも絵の問題から外すなら `noImage: true` |
| `kana` | | カタカナの発音の目安(省略可)。**補助情報**で、主な学習情報はフランス語表記と日本語訳 |
| `ex` / `exJa` | | 例文と訳。**両方そろえる**(片方だけはエラー) |
| `pos` | 名詞以外 ○ | `noun verb adjective adverb pronoun preposition conjunction interjection expression article numeral` |
| `level` | 推奨 | `A1 A2 B1 B2 C1 C2` |
| `alt` | | 別訳の配列。同じ訳(別訳含む)の単語は誤答選択肢に並びません |
| `syn` / `forms` / `note` / `ipa` | | 同義語 / 変化形 / 学習メモ / IPA。`forms` のキーは `plural`(複数形)`fem`(女性形)`mp`(男性複数形)`fp`(女性複数形)`present`(現在形)`past` `future` |

エラー(✗)は修正必須です(エラーのある単語はゲームから除外され、コンソールにID付きで表示されます)。
警告(△)は確認事項です(`level` 未指定、日本語訳の重複、例文に単語が見つからない、など)。

### 品詞別の必須項目

共通: `id` `cat` `fr` `ja`、例文と訳(`ex` / `exJa`。両方そろえる)、`level`。

| 品詞 | `pos` | 冠詞 `art` / 性 `g` | 変化形 `forms` |
|---|---|---|---|
| 名詞 | (省略) | **必須**。`le` `la` `l'`、性 `m` `f`。母音・無音の h で始まる語は `l'` だが、**性は別に決める**(`l'an` は男性、`l'eau` は女性)。`un` `une` `les` `des` は使わない | 複数形が不規則なら `plural` |
| 動詞 | `verb` | `''` | `present` に**6人称**を `je … , tu … , il … , nous … , vous … , ils …` の順で(母音の前は `j'`。代名動詞は `je me … , tu te … , il se …`)。**不定詞で登録**し、活用形を `fr` にしない |
| 形容詞 | `adjective` | `''` | `fem`(女性形)は**必須**。`mp`(男性複数形)・`fp`(女性複数形)も入れる(推奨) |
| 代名詞・前置詞・接続詞・副詞・数詞 など | `pronoun` `preposition` `conjunction` `adverb` `numeral` … | `''` | 不要 |

### カテゴリと品詞の扱い

- カテゴリ(`cat`)は図鑑の絞り込み・並び順・「カテゴリ実績」に使われます。**既存のカテゴリで足りるなら新設しません。**新設するときは `CATEGORIES` の末尾に足します(3語以上たまると、カテゴリ実績に表示されます)。
- 品詞(`pos`)は誤答選択肢の選び方(学習済み > 同カテゴリ > 同品詞)と、図鑑の表示に使われます。アプリが許可している品詞だけが使えます(上の表)。
- 絵文字は名詞だけに付けるのが原則です(推奨。`validate` は検査しません)。出荷済みの語のうち「あいさつ」の一部には例外があります。**絵文字が他の語と重複するとエラー**です(絵→仏の問題の正解が曖昧になるため)。

### 例文・日本語訳・選択肢の作り方

- 例文は**自然なフランス語**で、学習する語の使い方がわかるものにします(その語が例文の中に含まれていること)。
- 日本語訳は学習者にとって分かりやすい、一般的な訳にします。訳の違う別の意味は `alt` に足します。
- 4択問題の選択肢(正解1+誤答3)はゲームが自動で作ります。**同じ日本語訳(`alt` を含む)の語は、互いに誤答として並びません。**したがって、既存の語と同じ訳の語を足すと警告になります。区別したいときは訳を具体的にします。
- **日本語訳・絵文字は、ほかの語と重複させません**(選択問題の正解や「絵→仏」の問題が曖昧になるため)。完成文(`fr`)も、ほかの構文と重複させません。
- 実質的に同じ意味の語(同義語など)は、不用意に追加しません。必要なら `syn` に書き、訳を書き分けます。
- **アクセント記号だけが違う語は、同時には登録できません。**重複の判定(`WordLib.fold`)がアクセントを無視するため、たとえば `où`(どこ)がある状態で `ou`(または)を足すと警告になります。どうしても必要になったときは、重複判定の例外の設計(スキーマの変更)を先に決めてください。
  - **認めている例外は、次の1組だけです。** `mais`(w134・接続詞「しかし」)と `maïs`(w255・名詞 `le maïs`「とうもろこし」)。どちらも標準的で意味も品詞も異なる別の語で、綴りの `ï` が唯一の違いなので、どちらかを別の語に置き換えることはできません。この2語は、冠詞を含む表示が `mais` と `le maïs` で別になるため、重複の検証(表示形で判定)にも、4択の選択肢の重複にもあたりません。日本語訳も違い、検索(`WordLib.fold` はアクセントを無視)では、どちらで検索しても2語が見つかります(これは仕様です)。この2語の ID・綴り・意味は変更しないでください。
  - **例外を増やすことはできません。**アクセントだけが違う語は、これまでどおり同時に登録できず、`tests/content_accent_exception.test.js` が「アクセントを無視すると同じ綴りになる語の組は、この1組だけ」であることを確認しています。新しい例外が必要なときは、その理由(別の語であること・区別できること)を、先にこの項に書き、このテストの期待値を更新してください。

## 4. 構文(`data/phrases.js`)

### 必須項目

`id` `level` `scene` `fr` `ja` `pattern`(型)`chunks`(意味のまとまり。目安は2〜5個。検証の上限は8個)`grammarNote`(文法解説。140文字以内)`wordIds`。任意: `cloze`(空欄補充)`slots`(応用例)`equiv` `formats`。
各項目の意味は `data/phrases.js` の冒頭コメントにもあります。`scene` は `PHRASE_SCENES` に登録したキーにします。

### chunks の仕様

`chunks` は、語順整序と解説に使う**意味のまとまり**です。空白での単純分割はしません(`m'appelle` `s'il vous plaît` `d'un stylo` などを1単位で保持する)。

- 書式: `C(t, ja, after, sp)`。`t` = 語句、`ja` = その意味、`after` = 直後に付く句読点(`','` `'.'` `' ?'`)、`sp: false` = 直後に空白を入れない。
- **`fr` は `chunks` を順に連結した文と完全に一致**させます(語順整序の正解になります)。句読点は `after` に書きます。
- **2個以上あると語順整序の問題が出ます**(1個だと出ません)。`formats` を省略すると、選択 + 整序(`chunks` が2つ以上)+ 空欄(`cloze` があるとき)を出題します。

### 空欄補充(`cloze`)

- `chunk` = 空欄を含む `chunks` の番号、`pre + answer + post` = その `chunk` の `t` と一致、`options` = 候補(`answer` をちょうど1つ含む。検証は3つ以上を求めますが、既存はすべて**4つ**なので4つにそろえます)。
- 候補は「**その空欄に入れて文法的に成り立つのは正解だけ**」になるよう選びます(`un/une/des/la` は可、`le/du` は不可、など)。`ou` を空欄にして `et` を候補に入れると文が成り立ってしまう → 冠詞など別の位置を空欄にします。
- 誤答候補を入れた文が、ほかの構文の文と同じにならないことも検証されます。ただし、**誤答候補が別の自然な文になっていないかは、人が確認します**(§6)。

### 応用例(`slots`)・`equiv`

- `slots`: `chunk` の語句だけを入れ替えても文法的に正しくなるものだけを並べます(冠詞・性数・前置詞が変わるなら、その形ごと `t` に書く。例: `du lait` / `de l'eau`)。
- `equiv`: 同じ意味で言い換えられる構文の `id`。選択問題で互いに誤答候補にしません。片方向だけの指定は警告です。

### レベルと説明

- `A1` の構文は、`wordIds` と `slots` を含めて **`A1` の単語だけ**を参照します(`A2` の語を使うなら構文も `A2` にする)。`npm run validate` がエラーにします。
- 学習者のレベルに合った、短くて正確な文法解説(`grammarNote`)を付けます。
- 完成文(`fr`)と日本語訳(`ja`)は、ほかの構文と重複させません(選択問題の正解が曖昧になるため)。

## 5. 単語と構文の相互参照

- `wordIds: ['w21', 'w104']` … その構文で学ぶ主な単語の ID。単語図鑑の「この単語を使う構文」、構文を始める前の「まだ習っていない単語」の一覧、新しい構文を選ぶときの優先順位に使われます。
- `slots` の `options[].wordId` … 応用例で入れ替える語句に対応する単語の ID(任意)。
- **参照できるのは `data/words.js` に実在する ID だけ**です(無いとエラー)。構文を追加するときは、必要な単語を**先に**追加します。
- 参照する単語は、その構文のレベル以下にします(`A1` の構文は `A1` の単語だけ)。

## 6. 品質基準と、人が確認すること

自動検証が見るのは**データの形式と、機械的に判定できる決まり**です。フランス語そのものの正しさは、自動では保証できません。**形式が正しくても、フランス語が誤っていれば不適切な教材です。**追加するたびに、次を人が確認してください。

### 単語

- 既存の語と実質的に重複していない(訳・綴り・意味)。
- 名詞の**性・冠詞**が正しい(母音・無音の h の `l'`、有音の h、`l'an` / `l'eau` のような性の区別)。
- 動詞の6人称の活用が正しい(不規則動詞、`-er` の綴りの変化、代名動詞の `me/te/se`)。
- 形容詞の女性形・複数形が正しい(`fem` / `mp` / `fp`)。
- 例文が自然で、その語の典型的な使い方になっている。日本語訳が自然で、例文の意味と一致している。
- 辞書で判断できない表現は、文法的な説明(`note`)を付けて確認する。

### 構文

- フランス語の文法と語法が正確で、**実際に自然な表現**である(文法的に正しくても不自然な文は避ける)。
- 日本語訳が自然で正確。完成文と `chunks` が一致している。
- 空欄補充の正解が**一意**に定まる。誤答候補を一つずつ入れてみて、別の正解が成立しない(文法的にも、意味の上でも)。
- `slots` のどの語句に入れ替えても、文が正しい。
- 文法解説がレベルに合っている(1文〜2文で、140文字以内)。

## 7. 既存の学習記録との互換性

学習記録は教材の **ID** をキーに保存されます(保存形式の詳細は [SPECS.md](SPECS.md) の「保存データ」)。教材の追加で、既存の学習履歴を失わないために、次を守ります。

- **既存の ID を変更・削除・再利用しない。**変えると、その語・構文の記録が別の教材に付いたり、失われたりします。
- 既存の語・構文の**意味**(フランス語・日本語訳・冠詞・性・場面・レベル)を、無関係な作業のついでに変えない。別の内容にしたいときは、**新しい ID で追加**します。
- 誤りを直すときは、**同じ ID のまま**内容を直します(その語・構文の意味が変わらない範囲で)。
- 教材と無関係な、既存データの整形・一括変更をしない(`data/` は自動整形の対象外です)。
- 新しい教材は「未学習」から始まり、既存の記録は影響を受けません。教材の並び順がそのまま学習順なので、末尾に足せば既存の学習順は変わりません。
- 教材に無い ID の記録も保存データには残ります(教材を一時的に外しても履歴は消えません)。ただし、教材は削除しない運用です。ID を欠番にすると `validate` と基準ファイルのテストがエラーにします。
- 保存形式そのものを変える必要が出たときは、変更の必要性を説明し、移行処理(旧形式 → 新形式)と、退避キーへのバックアップを検証してから変更します。

## 8. 出荷済みの教材の保護(基準ファイル)

出荷した教材は、`tests/fixtures/` の基準ファイル(`baseline_content.json` = 初版、`baseline_content_r2.json` = 第2弾 …)に、ID・並び順・重要な内容(単語はフランス語・日本語訳・冠詞・性、構文は完成文・日本語訳・場面・レベル)を記録して保護します。`tests/content_baseline.test.js` が確認します。

- 教材を**足すだけのときは、基準ファイルを編集しません**(追加分は保護の対象外で、検証と各テストが見ます)。
- **出荷するとき**は、既存のファイルを**編集せず**、新しい `baseline_content_r3.json`(以降 `_r4` …)を**追加**します。形式は `baseline_content_r2.json` と同じで、`words` / `phrases` にはそのとき追加した分だけを、`categories` / `scenes` には新しく増えた分だけを書きます。`tests/baseline.js` が自動で読み込みます。
- 既存の教材の誤りを意図して直すときだけ、該当行を更新します(ID は変えません)。なお、基準ファイルが保護するのは上記の項目だけで、学習メモ(`note`)や文法解説(`grammarNote`)の修正では更新は不要です(`w67` と `p84` の説明の修正でも、基準ファイルは変更していません。内容は `tests/content_fixes.test.js` が確認します)。

## 9. 検証の範囲(何が自動で、何が人の確認か)

| 確認する場所 | 内容 |
|---|---|
| `npm run validate` の `validate_words.js` / `validate_phrases.js` | データの形式(必須項目・品詞・冠詞と性・重複ID・存在しない単語ID・`chunks` と `fr` の一致・空欄の候補・場面の登録など)。エラーのある教材はゲームから除外される |
| `npm run validate` の `validate_policy.js` | 編集ルール(ID の連番・動詞の6人称・形容詞の女性形・絵文字の重複・A1 の構文が A1 の単語だけを参照)。ゲームの動作には影響しない |
| `npm test` | 上記に加えて、出荷済み教材の保護、問題生成・採点・復習・保存・HTML の安全性、数千語の規模でも出題が成立すること(`tests/app.test.js` `tests/wordlib.test.js`)など |
| **人の確認(§6)** | フランス語の正しさ・自然さ、誤答候補が別の正解にならないこと、日本語訳の自然さ |

### 教材を足してもテストが壊れないための設計

- **件数の上限は置かない。**件数のテストは「出荷時より減っていない」という下限だけを見ます。
- 完全一致で確かめる検査(検索結果の一覧など)や、初版の教材だけを前提にした検査(初版の品詞・レベルの制限など)は、**初版の教材だけ**に絞って比べます(`tests/baseline.js` の `onlyBaseline` / `WORD_COUNT` / `PHRASE_COUNT`)。追加した語・構文が混ざっても失敗しません。
- ID の重複、データ検証、問題生成、採点、復習、保存形式、HTML の安全性、BOT の表示のテストは、追加した教材にもそのまま適用されます。追加分の品詞は、アプリ本体(`src/lib/wordlib.js`)が許可している品詞なら使えます。
- 教材の正確さ(性・活用・形容詞の性数)は、データとは独立した正解表(`tests/content_r2.test.js`)でも確認します。新しい教材を出荷するときは、同じ考え方で正解表のテストを足してください。
